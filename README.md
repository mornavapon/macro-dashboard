## เนื้อหาแต่ละหน้า

### หน้า 1 · ดัชนีโลก
| หัวข้อ | รายละเอียด | อัปเดต |
|---|---|---|
| ตารางดัชนีสำคัญ | S&P 500, NASDAQ, SET, HSCEI, SSE Composite, VN-Index: ระดับดัชนี / Market Cap / P/E / P/BV / วันที่ข้อมูล · แตะชื่อดัชนีเพื่อเปิดกราฟใน TradingView | ทุก 3 ชม. |
| ภาพวงกลมตลาดหุ้นสหรัฐฯ | วงใหญ่ = ตลาดหุ้นสหรัฐฯ แบ่งฝั่ง NYSE / Nasdaq, ซ้อนด้วย S&P 500 และ Dow (พื้นที่ ≈ Market Cap) | วันที่ 1 และ 15 ของเดือน |
| กราฟ VIX 2 ปี | เส้นคงที่ที่ 18 และ 30 พร้อมระบายสีพื้นหลัง 3 โซน | ทุก 3 ชม. |
| กราฟ SOXX / S&P 500 | หุ้นชิปนำตลาดไหม (เริ่ม = 100) + เส้นเฉลี่ย 200 วัน + สรุปว่าเอนไป Risk-on หรือ Risk-off | ทุก 3 ชม. |
| Market Breadth S&P 500 | % หุ้นใน S&P 500 ที่อยู่เหนือเส้นค่าเฉลี่ย 200 วัน (คำนวณเองจากหุ้นทุกตัว) + สรุปว่าขึ้นแบบกระจาย/กระจุก + กราฟเทียบดัชนี | วันละครั้ง 06:37 น. (อ.–ส.) |

### หน้า 2 · อเมริกา
| หัวข้อ | รายละเอียด |
|---|---|
| GDP | ขนาดเศรษฐกิจ + การเติบโต QoQ ย้อนหลัง 4 ไตรมาส (ปุ่มไป investing.com) |
| ประชุมเฟด | ตารางประชุม FOMC ทั้งปี พร้อมผลการตัดสินใจ |
| CPI | เงินเฟ้อ YoY (ปุ่มไป investing.com) |
| กราฟเพิ่มเติม | DXY, อัตราผลตอบแทนพันธบัตร (2Y, 10Y, ส่วนต่าง), NFP + อัตราว่างงาน, งบดุลเฟด (ย้อนหลัง 2 ปี) · หนี้รัฐบาลกลาง + เพดานหนี้ (ย้อนหลัง 5 ปี) |

ทุกกราฟบอกวันที่ของข้อมูล ความถี่ที่อัปเดต และกำหนดออกครั้งถัดไป · ดึงข้อมูลทุก 6 ชม.

### หน้า 3 · ไทย
| หัวข้อ | รายละเอียด | แหล่งข้อมูล |
|---|---|---|
| GDP | ขนาดเศรษฐกิจ + การเติบโต QoQ | สศช. (NESDC) |
| ประชุม กนง. | ตารางประชุมทั้งปี พร้อมผลการตัดสินใจ | ธปท. |
| เงินเฟ้อ | CPI ไทย | สนค. (TPSO) |
| ส่งออก | มูลค่าส่งออกรายเดือน + การเติบโต | กระทรวงพาณิชย์ |
| BOI: ต่างชาติยื่นขอลงทุน | ยอดคำขอของต่างชาติสะสมตั้งแต่ต้นปี (มูลค่า + จำนวนโครงการ) + 5 ประเทศ / 5 อุตสาหกรรมแรก + ยอดรายปี + สรุปว่ากระจายตัวหรือกระจุกโครงการใหญ่ | BOI (อ่าน PDF อัตโนมัติ) |
| FDI: เงินลงทุนจริงจากต่างชาติ | FDI สุทธิรายไตรมาส (ล้านดอลลาร์) + เทียบปีก่อน + รวมรายปี | แบงก์ชาติ (PDF ตารางแนบรายงานเศรษฐกิจ) |
| กลุ่มนักลงทุน | ซื้อ/ขายสุทธิ เดือนก่อน / เดือนนี้ / ตั้งแต่ต้นปี + รายละเอียดเดือนนี้ | ตลาดหลักทรัพย์ฯ |
| MSCI ปรับหุ้นไทย | รายชื่อเพิ่ม/ตัดออกล่าสุด (ดัชนีหลัก + Small Cap) และรอบถัดไป | MSCI |
| เงินต่างชาติในตราสารหนี้ไทย | สรุปภาษาง่ายๆ ว่าเงินไหลเข้า/ออก + ตาราง วันล่าสุด / 5 วัน / เดือนนี้ / ต้นปี (แยกระยะสั้น-ระยะยาว) + กราฟรายเดือน 24 เดือน + ยอดถือครองของต่างชาติ | ThaiBMA (Non-resident Flows) |
| พันธบัตรรัฐบาลไทย | yield 2 ปี / 10 ปี + ส่วนต่าง ย้อนหลัง 2 ปี และตารางเทียบ 1 ปีก่อน | ThaiBMA ผ่าน library settfex |

ดึงข้อมูลทุก 6 ชม. (MSCI ดึงวันละครั้ง · เงินต่างชาติในตราสารหนี้ดึง จ.–ศ. 08:41 / 12:21 / 16:51 น. · พันธบัตรไทยดึง จ.–ศ. 18:23 น. + รอบเก็บตกเช้าวันถัดไป)

> **settfex แยกส่วนต่างหาก:** ใช้สคริปต์ `scripts/fetch_settfex.py` workflow `update-settfex.yml` และไฟล์ `data/settfex.json` ของตัวเอง
> ถ้า settfex ติดตั้งไม่ได้หรือพัง จะขึ้น "ดึงข้อมูลไม่สำเร็จ" เฉพาะกล่องพันธบัตรไทย ส่วนอื่นไม่กระทบ

> **MSCI ทางสำรอง:** ถ้ารอบไหนดึงรายชื่ออัตโนมัติไม่ได้ หน้าเว็บจะขึ้นกล่องเตือนว่า MSCI ประกาศแล้ว
> ให้บอก Claude ว่า *"MSCI ปรับรายชื่อหุ้นรอบ … แล้ว ช่วยดึงข้อมูลมาแสดงให้หน่อย"*
> Claude จะใส่ข้อมูลใน `data/msci_manual.json` ให้

## การแจ้งเตือน (ntfy)

แจ้งเตือนส่งเข้าแอป ntfy โดยแต่ละหัวข้อเป็น workflow แยกกัน **ปิดเฉพาะอันที่ไม่ต้องการได้** ที่
**Actions → เลือก workflow → ⋯ → Disable workflow**

| Workflow | เวลาแจ้งเตือน |
|---|---|
| แจ้งเตือน GDP สหรัฐฯ | ล่วงหน้า 1 วัน (09:13 น.) |
| แจ้งเตือน CPI สหรัฐฯ | ล่วงหน้า 1 วัน (09:13 น.) |
| แจ้งเตือน ประชุม กนง. | ล่วงหน้า 1 วัน (09:13 น.) |
| แจ้งเตือน GDP ไทย | วันที่ตัวเลขออก (ตรวจ 12:13 น.) |
| แจ้งเตือน เงินเฟ้อไทย | วันที่ตัวเลขออก (ตรวจ 20:13 น.) |
| แจ้งเตือน ส่งออกไทย | วันที่ตัวเลขเดือนใหม่ออก (ตรวจ 13:13 และ 20:13 น.) |
| แจ้งเตือน ต่างชาติขายตราสารหนี้ไทยหนัก | เมื่อรวม 5 วันทำการไหลออกเกิน 20,000 ล้านบาท (ตรวจ จ.–ศ. 17:23 น.) เตือนครั้งเดียวต่อรอบ |
| แจ้งเตือน BOI ประกาศยอดขอลงทุนรอบใหม่ | เมื่อจับได้จากข่าวว่า BOI ประกาศรอบใหม่ (ตรวจทุกวัน 09:37 น.) → ให้มาบอก Claude |
| แจ้งเตือน FDI ไทย ไตรมาสใหม่ | เมื่อแบงก์ชาติออกตัวเลข FDI ไตรมาสใหม่ (ตรวจ จ.–ศ. 10:47 น.) |
| แจ้งเตือน MSCI ปรับหุ้นไทย | เช้าวันที่ MSCI ประกาศ และ 1 วันก่อนวันปรับพอร์ตจริง |

- ข้อมูลไทย (GDP, เงินเฟ้อ, ส่งออก) ไม่มีปฏิทินประกาศล่วงหน้าที่ดึงได้ จึงแจ้งในวันที่ตัวเลขออกแทน
- ไม่มีแจ้งเตือนประชุมเฟด (มีที่อื่นแล้ว) และไม่มีแจ้งเตือนดัชนีโลก
- ชื่อหัวข้อ ntfy เก็บไว้ใน secret `NTFY_TOPIC_MACRO` เท่านั้น (**ห้ามเขียนลงในไฟล์ของ repo นี้** เพราะ repo เป็น Public)
- ทดสอบการแจ้งเตือน: Actions → เลือก workflow แจ้งเตือน → Run workflow → ติ๊ก test

## เมื่อข้อมูลดึงไม่สำเร็จ

แต่ละส่วนแยกกัน: แต่ละดัชนี แต่ละช่องข้อมูล และแต่ละหัวข้อดึงแยกกัน ถ้าแหล่งไหนพัง ส่วนอื่นยังทำงานปกติ
- หน้าเว็บจะขึ้นว่า **"ดึงข้อมูลไม่สำเร็จ"** เฉพาะส่วนนั้น
- ถ้าเคยดึงได้มาก่อน จะแสดงค่าเก่าพร้อมป้าย **"⚠ ข้อมูลเก่า"**
- `–` ในตารางดัชนี = ยังไม่มีแหล่งข้อมูลสำหรับช่องนั้น
- ถ้าแหล่งข้อมูลเปลี่ยนรูปแบบ (เช่น สศช. เปลี่ยนไฟล์) ให้บอก Claude เพื่อหาแหล่งใหม่

## BOI ทางกึ่งอัตโนมัติ

เว็บ BOI มีระบบกันบอท บอทเลยหาลิงก์รายงานใหม่เองไม่ได้ แต่จะจับจากข่าวว่า BOI ประกาศแล้ว → หน้าเว็บขึ้นกล่องเตือน + ntfy
ให้บอก Claude ว่า *"BOI ประกาศตัวเลขรอบ … แล้ว ช่วยดึงข้อมูลให้หน่อย"* Claude จะเพิ่มลิงก์ใน `data/boi_reports.json` แล้วบอทอ่านตัวเลขเอง

## ปรับเกณฑ์แจ้งเตือนตราสารหนี้

เกณฑ์อยู่ที่ `BONDFLOW_THRESHOLD` ใน `scripts/send_alert.py` (ค่าเริ่มต้น 20,000 ล้านบาท ใน 2 ปีที่ผ่านมาเกินเกณฑ์นี้ไม่กี่ครั้ง) ถ้าอยากปรับ ให้บอก Claude

## งานดูแลรายปี

- **ปฏิทิน CPI สหรัฐฯ** ใส่ไว้ถึง ธ.ค. 2027 (`CPI_SCHEDULE` ใน `scripts/fetch_us.py`) ช่วงปลายปี 2027 ให้บอก Claude เพิ่มปีถัดไป
- **เพดานหนี้สหรัฐฯ** (`DEBT_LIMIT_HISTORY` ใน `scripts/fetch_us.py`) ถ้าสภาคองเกรสเปลี่ยนเพดานหนี้ ให้บอก Claude อัปเดต

## การติดตั้ง (ครั้งแรก)

1. สร้าง repo ใหม่บน GitHub เป็น **Public** (GitHub Pages ฟรีใช้ได้กับ Public เท่านั้น)
2. **Add file → Upload files** แล้วลากไฟล์และโฟลเดอร์ทั้งหมดไปวาง → Commit (โฟลเดอร์ `.github` อาจต้องสร้างผ่านเว็บเอง)
3. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save
4. **Settings → Actions → General** → Workflow permissions: *Read and write permissions* → Save
5. **Settings → Secrets and variables → Actions** → New repository secret ชื่อ `NTFY_TOPIC_MACRO` ใส่ชื่อหัวข้อ ntfy
6. **Actions** → รัน workflow *อัปเดตข้อมูล…* แต่ละอัน → **Run workflow**
7. เปิดเว็บที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`
